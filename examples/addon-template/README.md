# Бланк аддона

Скопируйте эту папку в `%APPDATA%\TerminalExplorer\Addons\` под своим именем — аддон
появится в главном меню при следующем его открытии. Меню перечитывает папку каждый раз,
перезапуск проводника не нужен.

## Что внутри

| Файл | Назначение |
|---|---|
| `addon.json` | манифест — единственный обязательный файл |
| `run.cmd` | то, что запускается; замените на своё |
| `README.md` | этот файл, аддону не нужен |

## Манифест

| Поле | Значение |
|---|---|
| `id` | идентификатор, уникальный среди аддонов |
| `name` | подпись в меню |
| `description` | пояснение, показывается в списке аддонов |
| `author`, `version` | ваши данные, на работу не влияют |
| `kind` | `executable` — внешняя программа. `builtin` зарезервировано за встроенными |
| `placement` | `main` — только главное меню, `context` — только контекстное, `both` — оба |
| `entry` | запускаемый файл относительно папки аддона: `.exe`, `.cmd`, `.bat`, `.ps1` |
| `arguments` | аргументы командной строки с подстановками (ниже) |
| `requiresFolder` | `true` — пункт неактивен, пока не открыта папка |
| `hidden` | `true` — запускать без окна консоли |

## Подстановки в `arguments`

| Подстановка | Во что превращается |
|---|---|
| `{folder}` | папка, открытая в проводнике сейчас |
| `{selection}` | путь выделенного объекта; пустая строка, если ничего не выделено |
| `{addon}` | папка самого аддона — для доступа к своим файлам рядом со скриптом |

Кавычки в `arguments` ставьте сами: пути с пробелами без них развалятся на части.
Именно поэтому в шаблоне написано `"\"{folder}\""`, а не `"{folder}"`.

Рабочей папкой процесса становится папка, открытая в проводнике, — не папка аддона.
Скрипты почти всегда работают с тем, что открыто у пользователя; до своих файлов
добирайтесь через `{addon}` или `%~dp0`.

## Проверка

1. Скопируйте папку в `%APPDATA%\TerminalExplorer\Addons\`
2. Откройте главное меню (`≡` в заголовке) → «Аддоны»
3. Пункт «Пример аддона» запустит `run.cmd` и покажет полученные пути

Если аддон не появился — скорее всего, в `addon.json` синтаксическая ошибка. Сломанные
манифесты пропускаются молча, чтобы один плохой аддон не мешал работе проводника,
так что проверьте файл любым валидатором JSON.
