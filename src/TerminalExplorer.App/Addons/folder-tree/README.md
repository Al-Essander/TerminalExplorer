# Генератор структуры папок

Встроенный аддон (`"kind": "builtin"`). Манифест лежит здесь, а реализация — внутри
проводника: окно на WPF нельзя вынести в отдельный скрипт, не превратив аддон
в самостоятельную программу.

Такая раскладка даёт то же, что и у внешних аддонов: аддон виден в папке, его можно
отключить, убрав папку, переименовать в манифесте или снять с закрепления.

## Что делает

Создаёт дерево каталогов по описанию: корень с изменяемым именем и до трёх уровней
вложенности. Структуру можно сохранить как шаблон и применять повторно.

Шаблоны хранятся отдельно от аддона — в `%APPDATA%\TerminalExplorer\folder-templates.json`,
потому что это пользовательские данные, а не часть программы.

## Как открыть

- Главное меню → «Аддоны» → «Генератор структуры папок»
- Панель аддонов слева (аддон закреплён: `"pinned": true`)
- `Ctrl+G`
- `TerminalExplorer.exe --folder-tree "C:\Projects"`

## Поля манифеста

`kind: builtin` означает, что `entry` и `arguments` не нужны — проводник опознаёт аддон
по `id` и вызывает свою реализацию. Для своих аддонов используйте `kind: executable`,
образец — в папке `example-addon`.
